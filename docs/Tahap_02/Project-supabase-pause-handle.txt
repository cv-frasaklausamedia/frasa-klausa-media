Membuat API route baru di Next.js (misalnya /api/keep-alive) yang melakukan satu *query* baca (read) sangat ringan ke Supabase, misalnya melakukan SELECT 1 baris data dari tabel bebas. Selanjutnya, buatkan konfigurasi vercel.json untuk mengatur Vercel Cron Job yang memanggil endpoint /api/keep-alive tersebut secara otomatis setiap 5 hari sekali. Tujuannya adalah untuk melakukan aktivitas database minimal agar proyek Supabase tidak terkena auto-pause.
